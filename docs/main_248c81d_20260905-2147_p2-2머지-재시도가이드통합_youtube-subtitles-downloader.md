## 3. 동작 원리 (쉽게)

- **왜 충돌이 났나**: p2-1 머지가 docstring을 `—`(긴 대시)로 적었고,
  p2-2가 같은 줄을 `-`(하이픈)으로 고쳤습니다. 같은 줄을 양쪽이 다르게
  바꿨으니 Git이 자동으로 못 고르고 사람에게 물은 것입니다.
- **해결**: 기능 차이가 아니라 표기 차이뿐이라 p2-2 쪽(하이픈)을 선택.
  하이픈 쪽이 Windows 콘솔(cp949) 크래시를 안 일으키는 버전입니다.
  해결 후 충돌 표시가 없는지, 컴파일이 되는지, 양쪽 기능 키워드가
  코드에 다 있는지(`recommend_retry`·`detect_title_lang`·`ask_save_location` 등)
  직접 확인했습니다.
- **교훈**: 같은 파일을 양쪽 브랜치가 동시에 만지면 이렇게 작은 충돌이 납니다.
  내용은 1줄이었고, 고치는 데 1분 걸렸습니다. 순서대로 하나씩 합치면
  이런 충돌이 어디서 왔는지 바로 압니다.
