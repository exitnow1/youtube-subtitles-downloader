## 3. 동작 원리 (쉽게)

- **작업 기록**: `runs` 테이블에 시작 시각을 먼저 적고(`running`과 같은 원리),
  끝나면 결과 카운트를 적습니다. 카운트는 전역 집계 리스트의
  전후 차이로 계산해서 기존 로직을 건드리지 않습니다.
- **로그 이중화**: `log()` 1회 호출 → 누적 로그 + 실행별 로그에 동시 저장.
  스케줄러 무질문 실행 때도 그대로 남으니 나중에 추적 가능.
- **실시간 갱신**: 처리 개수 10 단위로 대시보드 재생성. 실패해도
  다운로드는 계속됩니다(try/except 격리). 스캔·재시도 종료 시에도 1회 갱신.
- **소요 시간**: 시작·종료 ISO 시각 차이로 계산 (`3분 20초` 형태).
