## 3. 동작 원리 (쉽게)

- **증분의 의미**: 목록 보기는 유튜브에 물어보지 않습니다.
  이미 저장된 최신 스냅샷 + 자막 성공 기록을 대조만 합니다.
  새로 올라온 영상 파악은 스캔(모드 6) 때 이미 끝난 일이라,
  보기는 그 결과를 읽는 것입니다. 그래서何번을 봐도 요청 0회입니다.
- **상태 판정**: 영상별 최신 다운로드 상태가 success면 `[받음]`,
  나머지는 `[미수신:실패/미시도 등]`으로 표시합니다.
- **개수**: 표시 행이 200개로 잘려도 개수는 전체 기준이라 정확합니다.
- **업로드 날짜**: 목록 조회 데이터에 없어서 표시하지 않습니다.
  날짜 조건은 다운로드 실행 시(모드 1~3) 적용됩니다. 정직하게 표기했습니다.
- **반환값**: 표시된 행 목록을 돌려줘서 다음 기능(P5-6 미수신 다운로드)이
  그대로 재사용합니다.
