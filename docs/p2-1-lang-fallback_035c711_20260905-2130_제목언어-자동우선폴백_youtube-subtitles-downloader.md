## 3. 동작 원리 (쉽게)

- **문제**: 이전 순서는 제목을 보지 않았습니다. 영어 영상인데도 한국어
  자동자막부터 물어보는 식이라, ...(생략)... 순서가 비효율적이었습니다.
- **해결**: 1순위를 돌리면 필터가 영상 정보를 받으면서 실제 제목을 알게
  됩니다(추가 요청 없음). 그 제목에서 한글자·영문자를 세어 주 언어를
  판별하고, **자동자막을 기본으로 깔되 제목 언어를 먼저** 물어봅니다.
  이미 물어본 조합은 건너뛰어 헛요청을 안 합니다.
- **판별법**: `[가-힣]` 개수 vs `[A-Za-z]` 개수. 동점이면 ko.
  숫자·기호뿐이면 판별 불가 → 이전 순서 그대로.
