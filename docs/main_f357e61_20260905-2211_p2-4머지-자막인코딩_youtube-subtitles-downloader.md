## 1. 앱 전체 구조 (지도)

```
시작 시: 자막 설정 질문에 "인코딩" 1줄 추가 (Enter=UTF-8 / bom / cp949)
  → 영상마다: 저장 + 헤더 기입 (UTF-8 상태)
      → (신규) UTF-8이 아니면 목표 인코딩으로 변환 후 저장
  → DB 행마다 인코딩 기록 → 재시도는 그 행의 인코딩을 그대로 따름
```

```

```

## 3. 동작 원리 (쉽게)

- **문제**: 자막 파일은 항상 UTF-8로 저장됐습니다. 최신 기기는 괜찮지만,
  구형 TV·내비·구형 플레이어는 UTF-8 한글을 깨진 글자로 보여주거나,
  BOM(파일 맨 앞 3바이트 서명)이 없으면 인코딩을 못 알아봅니다.
- **해결**: 헤더까지 다 적은 뒤(UTF-8 상태), 마지막에 목표 인코딩으로
  변환합니다. `utf-8-sig`는 맨 앞에 BOM을 붙인 UTF-8,
  `cp949`는 한글 윈도우 기본 인코딩입니다.
  cp949에 없는 문자(이모지 등)는 `?`로 바뀌니, 그런 영상이면 UTF-8 유지를
  권장합니다 (변환 시 로그에 남음).
- **DB 연동**: 인코딩 선택을 행마다 기록합니다. 옛날 DB(컬럼 없음)는
  처음 열 때 자동 추가돼서 그대로 쓸 수 있습니다.
  재시도는 "그때 그 인코딩"으로 저장해 일관성을 유지합니다.
