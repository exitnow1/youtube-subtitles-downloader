## 1. 앱 전체 구조 (지도)


## 2. 사용 흐름 (이번 커밋 기준)

```
영상 URL (1개씩 입력, 빈 줄이면 시작/종료): https://.../watch?v=aaa
다음 URL (빈 줄이면 시작): https://.../watch?v=bbb https://.../watch?v=ccc
다음 URL (빈 줄이면 시작): (Enter)
[일괄] 직접 입력 3개 순차 처리
(자막 설정·조건 질문 1회)
[일괄] 1/3 ... [일괄] 2/3 ... [일괄] 3/3
```

단건 입력(1개+빈 줄)은 예전과 동일하게 동작합니다.

## 3. 동작 원리 (쉽게)

- **문제**: 모드 2는 URL 1개만 받았습니다. 5개를 받으려면 프로그램을
  5번 켜야 했고, 그때마다 설정·조건을 다시 물었습니다.
- **해결**: URL 수집 → 설정 1회 → 쿠키 1회 → 기존 `run_single` 반복.
  새로 만든 건 입력 수집뿐이고, 다운로드는 검증된 기존 함수를 그대로
  씁니다. 영상별 runs 기록·차단기·재시도 로직이 그대로 적용됩니다.
- **`do_cookie`**: 묶음은 첫 1회만 쿠키를 추출합니다 (브라우저 DB를
  5번 두드릴 필요 없음). 단건·폴백 호출은 기본값 True라 기존 동작 불변.
