├── subtitle_db.py                        … (C) 작업 기록 DB ← 이번에 새로 생김
└── Downloads/                            … 실행 결과물 (자막·DB·로그, 커밋 제외)

## 2. 사용 흐름 (이번 커밋 기준)

```
메뉴 1/2/3 (채널·개별·재생목록) 또는 4 (실패 재시도)
  → 자막 설정 (언어·자동자막·형식) + 조건 (날짜·길이·번호)
  → 영상마다: DB에 "시작" 기록 → 정보 1회 요청 → 조건 검사
      → 통과면 자막 저장 + 파일 상단 헤더 기입 → DB에 "종료" 기록
  → 모드 4: DB 실패 목록 → 번호 선택 → 지금 or 예약(30분후/21:30) 재시도
```

## 3. 동작 원리 (쉽게)

- **DB가 장부 역할**: 이전에는 성공·실패가 그때그때 화면에만 남았습니다.
  이제 영상 1개마다 "몇 시에 시작해서 몇 시에 끝났고, 제목·URL·결과·사유·파일경로"를
  `subtitle_jobs.db`에 한 줄씩 적습니다. 재시도할 때마다 새 줄이 쌓여
  "이 영상은 지금까지 3번 실패" 같은 이력이 남습니다.
- **재시도는 약하게**: 실패했던 영상이라 더 조심합니다.
  재시도 사이 8~15초 대기, 429가 3번 연속이면 나머지 중단(차단기).
  중단된 분량은 DB에 그대로 있어 다음에 이어서 할 수 있습니다.
- **예약은 기다리기**: `30분후`·`21:30`을 입력하면 그 시각까지 10초씩 끊어
  대기합니다. Ctrl+C로 취소할 수 있고, 프로세스를 켜 둬야 합니다.
- **헤더는 도장**: 자막 파일 맨 앞에 "언제 받았는지·무슨 영상인지·주소"를
  적어둡니다. vtt는 스펙에서 허용한 NOTE 주석으로, srt 등은 `#` 주석으로.
  이미 도장이 있으면 중복으로 안 찍습니다.
