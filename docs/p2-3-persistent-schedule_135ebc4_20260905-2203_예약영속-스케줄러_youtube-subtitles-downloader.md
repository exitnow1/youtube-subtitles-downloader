## 3. 동작 원리 (쉽게)

- **문제**: 기존 예약(`wait_until`)은 프로그램이 켜져 있어야 했습니다.
  노트북을 덮으면 예약이 같이 죽습니다.
- **해결**: Windows 작업 스케줄러라는 OS 기본 알람을 씁니다.
  `schtasks /create`로 "이 시각에 이 명령을 실행해"를 등록하면,
  PC만 켜져 있으면 앱이 꺼져 있어도 실행됩니다.
- **무질문 실행**: 스케줄러는 사람처럼 대답을 못 하니 전용 모드를 만들었습니다.
  `--retry-failed`는 실패 목록을 저장된 설정 그대로 재시도하고,
  없는 영상은 자동 제외, 팝업도 안 띄웁니다(서버실에서 멈추면 안 되니까).
  저장 위치는 지난번 값, 안전 대기·차단기는 그대로 적용됩니다.
- **당일/다음날 처리**: `schtasks` 날짜 형식은 윈도우 언어마다 달라서,
  당일 예약이면 날짜를 아예 안 넘기고(오늘 실행이 기본값), 다음날부터만
  날짜를 붙입니다. 등록 실패 시 정확한 원인과 직접 실행용 명령을 보여줍니다.
