## 3. 동작 원리 (쉽게)

- **문제**: 저장 위치가 코드에 박혀 있어(`Downloads\subtitles` 고정) 외장하드나
  다른 폴더에 받고 싶으면 코드를 직접 고쳐야 했습니다.
- **해결**: 시작할 때 한 번만 묻고, 대답을 전역 변수 `SUBTITLE_DIR`에 덮어씁니다.
  저장 경로 만들기·자막 파일 찾기·폴더 생성 함수가 모두 이 변수를 그때그때
  읽어 쓰기 때문에, 한 곳만 바꾸면 전체가 따라옵니다. (깃발 하나 꽂으면
  전군이 그쪽을 보는 것과 같습니다.)
- **기억**: 선택한 폴더는 `Downloads\.last_subtitle_dir`에 한 줄로 저장돼서
  다음 실행 때 Enter 기본값이 됩니다.
- **안전망**: 만들 수 없는 경로(예: 이상한 문자 포함)를 입력하면 경고를 내고
  기본값으로 돌아갑니다. 프로그램이 죽지 않습니다.

## 4. 전체 그림에서 뭘 추가·수정했나

| 구분 | 위치 | 내용 |
|---|---|---|
| 추가 | 상수 `LAST_DIR_FILE` + `_load_last_save_dir()` + `ask_save_location()` | 폴더 질문·지난값 불러오기·생성·실패 시 기본값·지난값 저장. 탐색기 복사 따옴표 제거, `~`·상대경로 정규화 포함 |
