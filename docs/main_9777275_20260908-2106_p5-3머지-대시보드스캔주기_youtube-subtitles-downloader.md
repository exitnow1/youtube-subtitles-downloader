## 3. 동작 원리 (쉽게)

- **대시보드**: DB에 이미 있는 스캔·다운로드 기록을 HTML 한 장으로 그립니다.
  유튜브에 새로 물어보지 않아 차단과 무관합니다. 제목의 `<script>` 같은
  위험 문자는 이스케이프해서 파일이 깨지지 않습니다.
- **빨강의 뜻**: 자막 성공 기록이 없는 영상(미시도·실패·스킵·자막없음 중
  성공이 아닌 전부... 정확히는 성공 제외). 당장 받을 후보가 빨강입니다.
- **스캔 주기**: 기존 재시도 스케줄러와 같은 schtasks 인프라를 씁니다.
  매일 HH:MM 또는 N시간마다 중 선택, 기본값은 설정 `scan_interval_hours`(24).
  당일/다음날 날짜 문제는 daily/hourly 형식이라 발생하지 않습니다.
- **모드 5 확장**: 조회 접두사를 재시도+스캔 둘 다로 넓혔을 뿐 삭제 방식 동일.
